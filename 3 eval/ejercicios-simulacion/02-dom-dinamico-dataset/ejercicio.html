Ejercicio 02 — DOM dinámico y data-* ⭐ Fácil

Dado el array de empleados de abajo, crea dinámicamente las tarjetas en el contenedor #listaEmpleados.

Tareas

  1. Recorre el array con forEach
  2. Por cada empleado, crea un article con createElement
  3. Guarda en atributos data-*: data-id, data-nombre, data-departamento, data-salario, data-activo
  4. Aplica la clase empleado + activo o inactivo según emp.activo
  5. Crea dentro un h3 con el nombre, un p con el departamento, un p con el salario (formateado con toFixed(2)) y un span.badge con el estado
  6. Usa appendChild para insertar cada tarjeta en #listaEmpleados
